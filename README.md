# Бодреев — мастерская пивоварения. Вариант 2

Отдельная концепция сайта BodreevShow. Первая версия сохранена в соседнем проекте `bodreevshow-redesign` и не изменялась.

## Открыть

Откройте `index.html` двойным щелчком. Для локального сервера: `python3 -m http.server 8766`, затем http://127.0.0.1:8766/. Никаких npm-зависимостей и сборки для просмотра не требуется.

## Изменения

- Новое предложенное позиционирование: мастерская домашнего пивоварения. Кириллический знак, локальные шрифты Oswald и Manrope, тёмно-зелёный и оранжевый цвета.
- Маршруты «Первая варка», «Знакомый вкус», «Свой эксперимент».
- Каталог с категориями, совместимыми с поиском, и понятным действием на каждой карточке.
- Рецепты: избранное в этом браузере, прямые ссылки `recipes.html#recipe-ID`, печать, скачивание, сохранённые исходные переносы строк.
- Статьи: ориентировочное время чтения (180 слов в минуту), содержание по реальным заголовкам, версия для печати.
- Главное меню сосредоточено на наборах, рецептах, знаниях и сообществе. Мерч, Пивотрон и радио доступны в нижнем меню.
- Статические CSS/JS подключаются с хешем содержимого: браузер не смешивает старые и новые версии файлов при обновлении.

Это дизайнерские и UX-гипотезы. Влияние на продажи и узнаваемость не измерялось.

## Содержание и ограничения

56 HTML-страниц: главная, 35 рецептов в библиотеке, каталог 10 наборов и Коробка № 1, 3 футболки, Пивотрон, 50 полных статей и одна страница о недоступном исходнике. Проверенные данные оригинала — снимок 16 сентября 2026 года. Нет выдуманных отзывов, наград, сроков доставки, состава наборов, крепости или горечи.

`noindex,nofollow,noarchive` на каждой странице. Реальные формы WordPress, аналитика и база лотереи не перенесены. Кнопки заказа только готовят письмо; отправляет его сам пользователь. Платежей нет. Для mailto нужна настроенная почтовая программа.

Избранное хранится локально. Если браузер запрещает localStorage, оно доступно только до закрытия страницы и сайт показывает пояснение. Прямую ссылку с localhost может открыть только пользователь этого компьютера; общедоступной она станет после публикации.

Пивотрон обрабатывает Excel/CSV в браузере. Колонки: «Имя пользователя», «Сумма, RUB», необязательная «Дата и время», также «Имя» и «Сумма». Файл до 5 МБ. Розыгрыш выбирает уникальные имена с учётом количества билетов; локальная история — последние 100 победителей.

Изображения товаров и материалы: BodreevShow, карта источников в `assets/sources.json`. Исключения исходного сайта: `docs/source-notes.md`.

Главный фон `assets/workshop-hero.webp` — специально созданная через ImageGen концептуальная иллюстрация. Это не фотография реального товара или мастерской; отметка есть на первом экране. Оригинал создан 16 сентября 2026 года.

Локальные шрифты: Manrope и Oswald, SIL Open Font License. Тексты лицензий в `assets/fonts/`. SheetJS 0.16.9, Apache-2.0, источник https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.16.9/xlsx.full.min.js (та же версия, что у оригинала).

## Редактирование и проверка

Основной контент: `content.json`. Общий шаблон и новая главная: `scripts/v2_templates.py`. Генератор: `scripts/build.py`. Базовые стили: `styles.css`, оформление второго варианта: `brand.css`, локальные шрифты: `fonts.css`. Сценарии диалогов: `app.js`; фильтры и избранное: `brand.js`.

```sh
python3 scripts/build.py
python3 scripts/check.py
node --check app.js
node --check brand.js
node scripts/raffle.test.cjs
```
