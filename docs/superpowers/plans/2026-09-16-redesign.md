# План реализации BodreevShow

**Goal:** Современная полная статическая версия сайта с локальными файлами и GitHub Pages.
**Architecture:** Общий HTML-шаблон генерирует главную, каталоги и страницы статей из проверенного content.json. Общие CSS и JS, локальные WebP.
**Tech Stack:** HTML5, CSS, vanilla JavaScript; Python для подготовки файлов.
**Spec:** docs/superpowers/specs/2026-09-16-redesign.md.
