# BodreevShow — тестовый редизайн

Пользователь поручил создать современную HTML-копию bodreevshow.ru, сохранить файлы на компьютере, создать отдельный GitHub-репозиторий и опубликовать тестовую ссылку. Выбор дизайна делегирован исполнителю.

Дизайн: редакционная крафтовая эстетика, тёплая бумага, почти чёрная типографика, медовый акцент, крупный первый экран, оригинальные изображения. Адаптация к 360–1440 px, доступная клавиатурная навигация, reduced-motion.

Содержание: 10 наборов, коробка № 1, FAQ, контакты, рецепты с деталями, дайджест с отдельными статьями, 3 футболки и таблица размеров, Пивотрон. Источник и дата фиксации сохраняются. Цены, названия и инструкции не выдумываются.

Статический HTML/CSS/JS, относительные пути, локальные изображения, открытие index.html напрямую. Сервер и сборщик для просмотра не нужны. Контент статически отображается; JavaScript добавляет поиск, диалоги, фильтры, локальный импорт таблицы и выбор победителей.

Тестовый сайт обозначен как демонстрационный; noindex. Отправка заказов только через явно подписанное открытие почтовой программы. Не переносить сторонние метрики, рекламу, ключи, Firebase-конфигурацию и обработчики оригинальных форм. Пивотрон не подключается к базе оригинала: файл и история локальны.

Публикация: отдельный публичный репозиторий bodreevshow-redesign и GitHub Pages. Никаких изменений оригинального сайта.

Проверка: все локальные ссылки/картинки существуют, перенос каталогов сверяется по исходным данным, JS проходит syntax check, desktop/mobile осмотр, меню/поиск/рецепт/FAQ/заказ проверены в браузере, опубликованный URL проверен отдельно.
