# Вариант 2: мастерская Бодреева

Новый самостоятельный вариант по поручению пользователя. Первая версия сохранена. Концепция: «Бодреев — мастерская домашнего пивоварения»; это предложенное позиционирование, не юридическое название.

Изменения: различимый кириллический логотип, тёмный первый экран с оранжевым акцентом, крупная типографика, маршрут новичка, фильтр каталога, сохранение рецептов на устройстве, постоянные ссылки на рецепты, печать, содержание статей и время чтения.

Не добавлять выдуманные отзывы, награды, характеристики сортов, состав комплектов и сроки доставки. Все товарные факты из ранее проверенного content.json (снимок 16.09.2026). Нет обещаний роста продаж: это дизайн-гипотезы для последующей проверки.

Сохраняем статическую архитектуру, локальные файлы, тестовую маркировку, noindex, ручную отправку письма. GitHub пока требует входа пользователя.
